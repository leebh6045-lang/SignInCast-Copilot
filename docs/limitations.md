# 已知局限（M2 进行中）

> 诚实记录当前做不到的事。每完成一个里程碑就更新本文件。

## 接入与数据

1. **真实数据量很小**：线上账号只有 3 个课堂、6 个任务、2 条签到记录。功能链路已验证，但**不足以支撑统计显著性或"效果"类结论**。
2. **录制数据已脱敏**：`data/fixtures/http/` 是 2026-11-17 录制的真实响应，姓名/学号/加入码/头像已掩码（`meta.desensitized=true`）。重新录制后必须重跑 `scripts/desensitize_fixtures.py`（`make record` 已内置）。
3. **合成样例单独存放**：`data/fixtures/http-sample/` 仅供测试与 HITL 演示；真实回放走 `data/fixtures/http/`。
4. **默认 fake 模型**：默认不调用真实 LLM，输出由规则策略产生，**不代表真实模型质量**。
5. **服务端无分页**：列表接口全量返回，分页与截断在客户端完成（任务 50、名单 200、记录 500、学期统计 300）。
6. **RAG 是 TF-IDF 稀疏向量 + 关键词混合**：离线、确定性好，但不是神经 embedding，同义改写与跨语言检索弱（ADR-007）。
7. **评测是回放 harness**：验证工具接线、权限、终止与指标计算；**不是模型质量评测**（M3 才有）。
8. **只有两个角色**：教师 / 学生；`SERVICE` 角色未实现。

## HITL 与写操作

9. **真实写操作未在线上执行验证**：代码路径与契约已对齐（补签/请假均为 upsert），但为避免污染真实课堂数据，未对线上执行写调用。安全验证方式：在 SignInCast 建测试课堂 + 测试任务，再用 `--live` 执行。
10. **多学生动作非原子**：逐学生调用写接口，中途失败会留下部分已写记录；依赖服务端 upsert 幂等 + 重试收敛，没有跨学生事务。
11. **mock 模式禁止写操作**：回放数据不含写接口响应，`SignInCastWriter` 直接返回 `CONFIG_ERROR`，不会伪造成功。
12. **动作无自动过期**：待确认动作不会过期（M3 可加 TTL）；长期堆积需要人工清理。
13. **SQLite 单进程**：待确认动作/审计存在本地 SQLite，服务多实例部署需换集中存储。

## 工程质量

14. **会话已持久化但无摘要**：历史按条数截断（默认 20 条），没有滚动摘要；运行检查点仍未落库。
15. **API 无鉴权**：`/api/run` 与动作接口没有登录态，令牌仅作确认凭据；`GET /api/actions/{id}` 会返回令牌（TODO M2 补鉴权）。
16. **无并发控制/限流**：同一进程多人并发未做隔离与限流。
16b. **Web UI 无登录**：本地面板仅用于演示；`GET /api/actions/{id}` 会返回确认令牌。
16c. **数字校验是启发式**：0–4 的小数字放行；百分比允许由工具数字复算（容差 0.3pp）；无法覆盖文字化数字（如"三名学生"）。
16d. **报告是本地文件**：写入 `data/reports/`，未做权限隔离与清理策略。
17. **JWT 刷新只处理一次**：401 后重登一次再重试；并发请求共享 token，无刷新锁。
18. **上下文压缩是启发式**：极端情况下退化为 system + user 两条消息。
19. **工具结果裁剪是字符截断**：可能破坏 JSON 结构，M2 后半段改为结构化裁剪。
20. **trace 查看器只读**：有文本与静态 HTML，无交互过滤/搜索。
21. **无 CI**：检查靠本地命令（pytest / ruff）。
22. **成本估算基于固定价格表**：与实际账单可能有偏差。

## 安全与合规

23. **注入防护已做，但不完美**：检索内容已标注为数据并扫描可疑指令；用户侧注入依赖模型自身判断，未做独立过滤。
24. **登录响应不录制**：`RecordingTransport` 跳过 `/api/auth/login`，token 不入库。
25. **凭据只在本机 `.env`**：`.env` 已 gitignore；不要把账号密码写进代码、日志或提交记录。

## M3 评测局限

26. **评测数据是合成样例 + 录制数据**：30 条用例跑在 `data/fixtures/http-sample` 上，工具数据确定，但**不代表真实班级分布**。
27. **LLM judge 有偏差**：judge 与 Agent 使用同一模型，存在"自己评自己"的倾向；分数只用于横向对比，不等于客观质量。人工抽检 20% 尚未由作者本人完成（报告里给出建议抽检清单）。
28. **单次运行**：模型输出有随机性，单轮评测的波动未被置信区间覆盖。
29. **成本是估算**：价格表固定近似，不代表真实账单；延迟受网络影响。
30. **双模型对比是子集**：只在 10 条用例上对比 flash/pro，不能外推到全量。
