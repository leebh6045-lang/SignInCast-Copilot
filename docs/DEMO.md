# 3 分钟演示脚本（分镜 + 预期输出）

> 用途：面试/评审现场演示，或录制 3 分钟视频。
> 原则：先演示"能干活"，再演示"为什么可信"，最后用数字证明。

## 演示前检查（2 分钟）

```bash
cd SignInCast-Copilot
curl -s localhost:8000/health        # 期望: {"status":"ok",...}
.venv/bin/python -m app.cli --sample-fixtures "刚才那节课的签到情况怎么样？"
```

- 浏览器打开 `http://127.0.0.1:8000/`
- 准备两个终端：一个跑 `make api`，一个备用命令
- 可选：`make llm-smoke` 先确认模型可用（没有 Key 时用 fake 模型也能演示）

## 分镜

| 时间 | 画面 | 操作 | 讲解词 |
| --- | --- | --- | --- |
| 0:00–0:20 | 架构图 / 首页 | 打开 `/` | "这是接在已有签到系统上的 Agent 服务，不碰业务代码，通过 REST 集成；模型只做决策，数字由代码算。" |
| 0:20–1:00 | 教师提问 | 输入"刚才那节课的签到情况怎么样？"点发送 | "三步：定位课堂→找最近任务→取记录并本地聚合；回答里的每个数字都能在工具结果里找到。" |
| 1:00–1:30 | 学生视角 | 角色切"学生"，问"我的考勤怎么样？" | "同一套服务，学生只能查本人数据；越权请求会被工具权限拦截。" |
| 1:30–2:10 | HITL 卡片 | 右侧"待确认动作"点确认 → 点执行 | "模型只能提议，不能执行；确认令牌只走人工通道。mock 模式下执行会被明确拒绝——宁可拒绝，不伪造成功。" |
| 2:10–2:40 | 报告 / trace | 输入"生成这次课的报告"，展示生成路径；或 `--show-trace` | "报告落盘为 Markdown；每一步决策、工具结果、token 与耗时都有 trace，可复盘。" |
| 2:40–3:00 | 评测结论 | 切到 `docs/eval-report.md` | "30 条真实模型评测：完成率 93%→100%，judge 均分 4.5；越权/注入 0 违规；双模型对比见报告。" |

## 录制方法（macOS）

1. QuickTime Player → 文件 → 新建屏幕录制 → 选中演示区域
2. 按上面的分镜操作，语速放慢，每步停 1 秒
3. 导出 1080p，命名 `docs/assets/demo.mp4`（>25MB 建议放外部链接并在 README 标注）
4. 或纯命令演示：`ffmpeg -f avfoundation -i "1:0" -r 30 demo.mp4`（需授权）

## 现场兜底

- 模型不可用：`COPILOT_LLM_PROVIDER=fake` 走规则决策，功能链路不变
- 网络不可用：默认 `mock` 数据，纯离线
- 端口被占：`make api` 前改端口，或直接 CLI 演示
