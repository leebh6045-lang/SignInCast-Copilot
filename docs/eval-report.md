## 8. M3 真实模型评测（2026-11-18）

> 口径：**真实 LLM 决策 + 回放工具数据**（`data/fixtures/http-sample`）。工具数据确定，模型行为真实。
> 单轮评测，模型输出有随机性；judge 与 Agent 同模型，存在自评偏差（见局限）。

### 8.1 配置

| 项 | 基线 | 优化后 |

| 模型 | deepseek-chat | deepseek-chat |

| 只读工具缓存 | 关 | 开 |
| 用例数 | 30 | 30 |

### 8.3 基线 vs 优化：一个诚实的负结果

| 指标 | 基线 | 优化 | 变化 |
| --- | --- | --- | --- |
| 完成率 | 0.933 | 1.0 | +0.067 |
| 工具召回率 | 0.8 | 0.833 | +0.033 |
| P95 延迟 | 6291 ms | 6120 ms | -171 ms |
| 运行 tokens | 237346 | 249820 | **+12474（+5.3%）** |
| 运行成本 | $0.1312 | $0.1375 | **+$0.0063（+4.8%）** |

**结论：RAG top-k 5→3 + 工具缓存，本轮没有降低 token 成本，反而略升。**
原因分析：token 成本主要由"多轮决策 + 工具结果体积"决定，检索引用只占少数知识类用例的上下文；
本场景模型基本不重复调用完全相同的只读工具，缓存命中有限（主要收益在延迟，约 -2.7%，且处于单轮噪声范围内）。
因此**默认配置仍保持 `rag_top_k=5`（质量优先）**，缓存保留（延迟收益为正、无质量损失）。
这条负结果写进报告而不是隐藏——它说明"降本要按 token 构成做，而不是拍脑袋砍检索条数"。

### 8.4 双模型对比（10 条同一子集）

| 维度 | deepseek-flash | deepseek-v4-pro |
| --- | --- | --- |
| 完成率 | 100% | 100% |
| Judge 通过率 / 均分 | 90% / 4.6 | 80% / 4.5 |
| 平均步数 | 2.6 | 2.4 |
| 平均延迟 / P95 | 5897 / 11991 ms | 8797 / **25218 ms** |
| 单用例 tokens | 11726 | 10633 |
| 单用例成本 | $0.00683 | $0.00622 |

观察：
1. **质量接近**（judge 均分 4.5–4.6），但 flash 更"爱探索"（工具召回 0.9、步数 2.6），pro 更"爱澄清"。
2. **pro 的 P95 延迟高达 25 秒**，交互体验明显更差；单轮评测下抖动也大。
3. **不是"模型越强越好"**：pro 在"本学期每个学生缺勤几次"（T04）上仅追问班级未给统计，judge 2 分；flash 在"导出 Excel"（T07）上反复澄清，judge 3 分。
4. 结论：本场景默认用 `deepseek-chat`（最低成本、最低延迟、质量相当）；flash 可作为"更高工具探索率"的备选；pro 暂不推荐作为默认。

### 8.5 失败模式与已修复的工程问题

评测暴露了 3 个真实问题，其中 2 个已修：

| # | 问题 | 影响 | 处理 |
| --- | --- | --- | --- |
| 1 | thinking 模型要求回传 `reasoning_content` | flash/v4-pro 在第 2 步 400，完成率 70% | 消息模型增加 `reasoning_content` 并在上下文中保留；修复后两模型完成率 100% |
| 2 | 数字校验误杀用户输入中的数字 | 学生越权用例（N02）被误判失败 | 校验允许数字来自用户输入与会话历史；修复后 N02 通过 |
| 3 | v4-pro/flash 倾向"澄清"而非执行 | 报告/统计类用例 judge 2–3 分 | 属模型行为差异，记录为发现；不做提示词过拟合 |

剩余低分用例集中在"多课堂歧义"（如"这学期每个学生缺勤几次"没有指定课堂）与"报告类需要格式参数"，
模型选择先澄清。这提醒：**需求描述里的隐含上下文，应由 Agent 主动缩小范围或默认取最近课堂**，是后续可优化点。

### 8.6 安全指标

- 30 条用例 × 3 个模型共 70 次运行：**禁用工具调用 0 次**
- 学生越权、写操作越权、注入指令、无数据边界全部通过（judge 通过或明确拒绝）
- 数字校验在基线中拦截了 2 次不可溯源回答（T01/T10，单轮波动），在优化轮未出现

### 8.8 局限

1. 评测数据是合成样例（12 条记录/1 个班），不代表真实班级分布。
2. judge 与 Agent 同模型，存在自评偏差；分数只用于横向比较。
3. 单轮运行，未做多次重复与置信区间；T01/T10 的差异属于单轮波动。
4. 双模型对比只在 10 条子集上进行，不能外推到全量。
5. 成本按固定价格表估算，不等于真实账单。
